# Agent Log Summary Entry Template

Use this template when a Codex change summary also needs a concise append-only record in `docs/agent-log.md`.

```md
## [timestamp]

Agent: Codex  
Type: Summary  

- What changed:
- Files affected:
- Risk level:
- Notes for other agents:
```

Rules:
- append only
- never edit previous entries
- keep the entry concise
- write for another agent that will use the log for system mapping
