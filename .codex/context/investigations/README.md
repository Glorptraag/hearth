# Investigation Notes

This folder is for time-bound or question-driven context notes that may not deserve a permanent subsystem document.

These notes are temporary support artifacts unless later promoted into a stable subsystem explainer.

Use this folder for:
- debugging investigations
- temporary architecture tracing
- focused notes on one bug, one flow, or one migration

Naming guidance:
- `2026-03-28-onboarding-flow.md`
- `2026-03-28-notifications-api-trace.md`

If an investigation note remains valuable after the immediate task, promote its lasting insights into `.codex/context/subsystems/`.
