## How to Use This Index

### Finding prerequisites for a thread
Look up the thread ID → "Prerequisites" column shows what typically needs to be in place first.

Example: L3 requires L1 and L2 to be at least emerging.

### Finding what a thread enables
Look up the thread ID → "Enables" column shows which threads open up next.

Example: M1 enables M2, M3, M4, M5, M7.

### Understanding progression paths
Follow the thread IDs across domains to see cross-domain learning connections.

Example path: EF1 (Sustained Attention) → EF2 (Working Memory) → M2 (Operations) → M3 (Fractional Thinking)

### Planning observations
When you observe a child demonstrating a capability, use this index to:
1. Identify the primary thread
2. Check prerequisites (are they already developing?)
3. Check enables (what comes next?)
