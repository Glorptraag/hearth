> **One line:** Most homeschool apps help parents record what their children did. Hearth makes the parent a better educator. The Hearth Cycle is how: **Prepare → Learn → Notice → Turn**, every session, with Hearth teaching the parent a little more about how to teach, how to watch and how to build the next lesson each time round.

## 1. Why

**What parents actually lack.** The scarce thing for a home-educating parent is rarely content. Activities, curricula and printables are abundant and mostly free. What's scarce is the confidence and skill to use them well:
- knowing what to watch for
- recognising learning when it happens
- knowing what to do when it doesn't land
- structuring a session so it works
- trusting that what they're doing counts

Early-childhood educators and classroom teachers get years of training and supervised practice in exactly these skills. Parents get none.

**What Hearth already learned building the Logger.** Capture quality is a teaching-skill problem, not a form-design problem. A parent who knows what to look for writes a good log in twenty seconds. A parent who doesn't can't be rescued by fields or AI interpretation. That's why the Logger was reworked around watch-fors, and it points to the bigger opportunity.

**The positioning.**

| Most homeschool apps | Hearth |
|---|---|
| Plan the week, record what happened | Every session makes the next one better |
| Content library | Teaching craft, lesson patterns and child understanding |
| The record is the product | The parent's growing skill is the product; the record is a by-product |
| Generic or single-philosophy | Six traditions, applied as method, not vocabulary |

The membership promise becomes: *"You'll be a better teacher in three months than you are today, and you won't feel tested getting there."*

## 2. The cycle

```
            ┌──────────────────────────────────────────────────────┐
            ▼                                                      │
        PREPARE ──────▶ LEARN ──────▶ NOTICE ──────▶ TURN ─────────┘
   watch-for primed   the session     the log asks     the next session,
   lesson shaped      or play         about the        the next watch-for,
   from a pattern                     watch-for        a tool for the parent

        └──────────── underneath: the parent grows (hidden educator path) ─────────┘
```

| Stage | What the parent does | What Hearth gives | Already specced in |
|---|---|---|---|
| **Prepare** | Picks or plans a session, reads one watch-for | Tailored watch-for · a lesson pattern to shape it · one craft tool when it fits | watch-for v1 §3–5 · new: patterns, Lesson Builder (§4) |
| **Learn** | Runs the session or lets the play happen | Session steps on Today · the watch-for at hand | learning cycle v1 §7 |
| **Notice** | Answers the watch-for in a short conversation | Not-yet signs, prompts for the child's words | watch-for v1 §6 |
| **Turn** | Accepts or adjusts what's next | Next session (method turn) · next watch-for (Constellation) · a craft card when a pattern shows · a link to parents who hit the same thing | learning cycle v1 §4 · watch-for v1 §3.5, §7.7 · new: linked community (§7) |

The child moves through the Constellation. The parent moves through the educator path. The same cycle drives both.

## 3. Five capabilities Hearth builds in the parent

These are the five strands from watch-for v1 §7.1, now treated as the curriculum for the parent. Every piece of parent-facing content maps to one of them.

| Capability | The parent can… | Content that builds it |
|---|---|---|
| **Prepare** | decide what they're looking for and shape a session around it | lesson patterns · Lesson Builder · "plan backwards" craft |
| **Notice** | see the learning (and the not-yet) while it happens | watch-fors · not-yet signs · Know Your Child · observation guides |
| **Record** | keep evidence, not impressions | conversational log · "their words" craft · portfolio/HEU guidance |
| **Respond** | adjust in the moment and next time | respond practices · scaffolding craft · method turns |
| **Craft** | choose teaching tools on purpose, in their tradition | craft notes · tradition practices · theory cards · Craft library |

## 4. Lesson patterns and the Lesson Builder

This is the biggest new idea in the brief: teach parents *how to build a lesson*, instead of handing them more finished lessons.

### 4.1 Lesson patterns

A pattern is a reusable session shape, three to five moves long. Each pattern has a built-in watch-for slot and fits many DLOs. Patterns are philosophy-neutral structures; traditions map onto them and some patterns belong naturally to one tradition's method.

| Pattern | Moves | Watch-for slot | Natural fit |
|---|---|---|---|
| **Read · Tell back** | read once → child tells it back → one line written | what they tell back | CM, Classical |
| **Show · Try · Repeat** | short demonstration with few words → child tries → leave it out to repeat | does it independently / self-corrects | Montessori, practical life |
| **This · Show me · What is it?** | name → point → recall, across separate moments | which period they reach | Montessori, vocabulary |
| **Explore · Notice · Name** | open exploration → "what do you notice?" → give the word | names the property | nature, science, Unschooling |
| **Story · Draw · Recall** | told story → draw it next day → say it back on day three | what returns on day three | Waldorf |
| **Say · Repeat · Review** | introduce item → chant/repeat → spaced review | recall with or without prompt | Classical memory work |
| **Wonder · Find out · Share** | child's question → find out together → child explains to someone | explains in own words | Unschooling, inquiry |
| **Make · Talk · Improve** | make something → talk about it → make it again better | changes something on purpose | handwork, design |

There are about 8–10 patterns at launch. Each is authored once with:
- its moves
- 2–3 sentences of *why it works*
- common mistakes, written parent-to-parent ("talking too much in the demonstration")
- which watch-for evidence kinds it suits

### 4.2 The Lesson Builder

This extends **Plan something** (watch-for v1 §4). It must fit the five-minute rule; typical use is about two minutes.

1. **What are you doing?** The loose plan, in the parent's own words (exists).
2. **Hearth suggests the watch-for** (exists) **and a pattern** that fits the plan and the family's tradition: "This could work as *Explore · Notice · Name*."
3. **The parent sees the pattern's moves filled in with their activity:** "Let them scoop and pour freely → ask 'what do you notice about the cups?' → give the words 'full' and 'empty'." This fill is assembled from the plan text slots and pattern templates. It is not generated free text.
4. **Save.** The session card on Today now carries the moves and the watch-for.

Depth follows the educator path:
- **E1** sees the suggestion and can accept it.
- **E2** can pick between two patterns.
- **E3** sees the pattern's "why" and common mistakes.
- **E4** can build from scratch: start from a watch-for and pick moves.

Over time the parent stops needing the builder because they've internalised the patterns. That's the goal, and it's a measurable sign the product is working.

### 4.3 What this does to module content

Packs and modules don't go away; they become **worked examples**. Each module's approaches are re-tagged with the pattern they use, plus a short "How this lesson is built" note. A parent who runs the bread module learns *Show · Try · Repeat* and can apply it to the next thing they think of.

New content authoring re-balances:

| | Today | Proposed |
|---|---|---|
| Fully scripted activities (Pack → Module → Approach → Activity) | most effort | flagship packs only (Jumpstart Classical etc.) |
| Lesson patterns | — | ~10, deep quality |
| Craft notes and guides | — | ~24 notes + ~12 guides at launch |
| Child-understanding content | — | age-band guides + not-yet sign library |
| DLO watch-for data (`sign`, `notYet`, `evidence`) | partial | every DLO over time |

This also changes the content economics. Patterns × DLOs × traditions combine, so ten patterns and a well-authored DLO set cover more ground than hundreds of activities.

## 5. The Craft library

Most craft content arrives as morning cards, in context (watch-for v1 §5). The Craft library is where it all lives for the parent who wants to browse, re-read or go deeper.

| Section | Contents | Format |
|---|---|---|
| **How to watch** | observation basics, watching one thing, not-yet signs as information, recording their words, observing in play | short guides (≤ 5 min read), linked craft notes |
| **How to teach** | wait time, open questions, describe-not-praise, scaffolding (with · beside · watch), stopping while keen, spaced return | craft notes grouped, each with "try this today" |
| **How to build a lesson** | the patterns (§4.1), planning backwards from a watch-for, sizing a step, planning a block | pattern pages, Lesson Builder entry |
| **Your tradition** | the family's tradition(s) explained as method: stance, what it watches for, its practices, its rhythm | tradition note rendered + practices |
| **Know your child** | see §6 | per child |

Rules:
- The library is **ungated**. Anyone can read anything. The educator path only decides what gets *pushed* to a parent, never what they're allowed to see.
- **No courses, modules-for-parents, quizzes, certificates or completion percentages.** Guides are short and standalone.
- Every guide ends with one thing to try and a link to the relevant community thread.
- Guides are written in Hearth's own voice, describing methods in our words (pedagogy layer D45), with outside books and resources linked rather than quoted.

## 6. Know Your Child

"Make parents better at understanding and observing their kids" needs two things. One is general knowledge about children at this age. The other is specific knowledge about *this* child, drawn from the parent's own logs.

### 6.1 General: age-band guides

Short guides per band (2–3, 3–4, 4–5, 5–6, 6–8, 8–10…). Each covers:
- what learning typically looks like at this age
- what's normal that parents often worry about
- what to watch for in play
- how each tradition sees this age

The guides are neutral and authored, and surface on the child's profile and in morning cards around birthdays.

### 6.2 Specific: what Hearth has noticed about this child

A section on each child's profile, assembled deterministically from their logs with no AI. Only patterns with enough evidence are shown (honest density); nothing appears until there is enough to say.

| Pattern | Source | Example |
|---|---|---|
| How their learning shows most | `evidence` kind of saw-it results | "Sam shows what he knows by doing it more than by explaining it." |
| What they return to | `chooses` evidence, initiated signals, rhythm outcomes | "He's come back to counting and stones on his own five times this month." |
| When sessions go best | outcomes by time of day / weekday | "Morning sessions land better than afternoon ones." |
| Recurring not-yet signs | `notYet` chips | "Losing track past five keeps coming up — that's a common step, and here's what helps." |
| Recently shown | DLO bands shown | "Since September: counts objects reliably, retells a short story in order." |

Each line links to its evidence: the moments behind it. Each one also suggests a move: a craft note, pattern or watch-for. This is where noticing turns into understanding.

## 7. Community and resources, hooked in

### 7.1 Linked threads

Instead of a forum the parent has to go and browse, discussion attaches to the things Hearth already knows about:

| Attached to | Shown where | Example prompt |
|---|---|---|
| a not-yet sign | log follow-up, `event.stuck` card | "47 parents have worked through 'loses track past five'. See what helped." |
| a lesson pattern | pattern page, Lesson Builder | "How others run *Read · Tell back* with a 4-year-old." |
| a craft note | card, library | "Did wait time feel awkward at first? Others found…" |
| a method / rhythm | rhythm note | "Living book: when a book isn't landing." |
| a tradition | tradition page | general discussion for that tradition |
| an age band | Know Your Child guide | "Three-year-olds and sitting still." |

Posting from a log ("Ask other parents about this") opens a draft. It contains the watch-for and not-yet sign, with **no child name, no photo and no log text unless the parent types it in**.

### 7.2 People

| Role | What they do |
|---|---|
| **Parents** | ask, answer, share what worked |
| **Experienced guides** (invited, verified: trained teachers, early childhood educators, long-time home educators per tradition) | answer in threads, marked as guide answers; may write craft guides |
| **Hearth team** | moderation, surfacing best answers into craft notes |

The best community answers can be promoted into authored content. Each one is human-confirmed and credited, then becomes a craft note or a "what helped" line on a not-yet sign. The community keeps improving the library.

### 7.3 Resources

Curated outside resources are linked from craft guides, patterns and traditions, never embedded or quoted. These include books, short videos, the Queensland Home Education Unit and other state bodies' registration guidance, and local co-ops and events. Each link carries one line from Hearth on why it's worth the parent's time. No affiliate or transactional framing (no-freemium rule).

### 7.4 Existing work this replaces or extends

The earlier community prototype (`hearth-community-flow-v2.html`) was a stand-alone community area. This brief proposes linked threads as the primary entry, with a light "All discussions" view behind them. That prototype needs re-review against this model before any further build.

## 8. My Teaching (private, unscored)

The parent asked to track and improve teaching skills, but the growth model stays hidden. The resolution is a private record of *practice*, not a measure of *skill*.

| Shows | Doesn't show |
|---|---|
| Tools you've tried, with the session you tried them in | stage, level, score, percentage |
| Patterns you've used, and how often | streaks, missed days |
| Things you've noticed about each child (links to Know Your Child) | comparison with other parents |
| Watch-fors you've followed through to "shown" | anything framed as pass/fail |
| One reflective line per month, assembled from the above: "This month you tried wait time and used *Explore · Notice · Name* four times." | |

It's opt-in, reached from the profile and never pushed. It also gives an experienced parent something to look back on, which in user research is often what keeps people going.

This is decision B5. The alternative is no parent-facing view at all.

## 9. How it fits the existing architecture

| Existing piece | Role in the Hearth Cycle | Change |
|---|---|---|
| Learning cycle v1 (rhythms, methods, turns) | Learn → Turn for the child's next session | none |
| Watch-for v1 (watch-fors, morning cards, conversational log, educator path) | Prepare → Notice, and the parent's growth | add Lesson Builder pattern step; craft cards link to Craft library and threads |
| Pedagogy layer v1 (traditions, signals, practices) | tradition method content for Craft library and patterns | practices tagged to patterns |
| Constellation | where the child is; source of watch-fors | none (D54 holds) |
| Packs / modules | worked examples of patterns | re-tag approaches with patterns; add "How this lesson is built" |
| Sanity | all authored content | new kinds: `pattern`, `guide`, `ageGuide`; `craft` (from watch-for v1) |
| Postgres | user and community data | new: `threads`, `posts`, `thread_links`, `guide_roles`, `my_teaching` view (derived, not stored) |
| AI | unchanged | zero runtime calls; Lesson Builder fill is template slots; community search uses the existing cue index first |

**Content hierarchy note.** Pack → Module → Approach → Activity stays the structure for child-facing content. Parent-facing content is a parallel set of standalone knowledge notes: patterns, guides, craft notes, age guides and traditions. These are linked by ID and have no hierarchy of their own.

## 12. Risks

| Risk | Mitigation |
|---|---|
| Feels like homework or training for the parent | No courses, quizzes or certificates; everything is optional, short and tied to today; growth model hidden |
| Patronises experienced parents | Starting-stage question; "Go deeper" setting; ungated library; guides written peer-to-peer |
| Community becomes a moderation burden or a privacy risk | Linked threads (narrow topics) before open forums; no automatic sharing; invited guides; Phase 3 only |
| Content shift strands existing module investment | Modules re-framed as worked examples, not retired |
| Scope creep before expo | Expo carries the message and four patterns only |
| Traditions flattened into one generic "good teaching" | Patterns map to traditions explicitly; tradition section of the library describes each as method (pedagogy layer D45) |
